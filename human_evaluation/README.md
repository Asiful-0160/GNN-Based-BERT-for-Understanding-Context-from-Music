# Human-evaluation listening supplement

Open `index.html` in a browser to read the ten original captions and play the corresponding uploaded audio files. Keep the `audio` folder beside the HTML file. This is a local supplement; it has not been published online.

The questionnaire is copied unchanged from RESULTS/index.html. Audio is copied unchanged from the user-supplied Human Eval Audio folder. All ten expected paths, Q01.wav through Q10.wav, exist and their PCM data can be read completely. All files are mono, 22,050 Hz, 16-bit WAV. Eight are exactly 10 seconds; Q03 and Q09 are approximately 10.0078 seconds. No trimming or conversion was performed.

`audio_verification.json` records dimensions, duration, and SHA256 for each supplied file. Filename matching establishes the questionnaire mapping; the original frozen retrieval-to-source manifest was not supplied, so upstream clip identity has not been independently verified.

The page retains its original rating controls and CSV download. Any newly entered ratings are separate from the frozen five-listener study and must not replace its published results.

This supplement accompanies the report's Task-4 human-evaluation methodology and results. The PDF does not embed audio. A repository or hosted supplement link can be added to the report once available.
